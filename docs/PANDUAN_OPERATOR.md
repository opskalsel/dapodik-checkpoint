# Panduan Operator — Dapodik Checkpoint

## 1. Masuk
1. Buka alamat aplikasi.
2. Klik **Masuk Operator**.
3. Isi username & password.
4. Jika login pertama dengan password sementara, Anda akan diarahkan mengganti password.

## 2. Dashboard
1. Pilih **Semester** dan **Tahun Pelajaran** (dropdown).
2. Klik **Muat Progres** untuk melihat progres total & per tahap.
3. Klik **Lanjutkan Checklist** untuk mulai bekerja.

## 3. Checklist
1. Pilih tahap (1–12) di navigasi kiri.
2. Pilih **Metode Update** (Installer / Patch). Bagian metode lain otomatis disembunyikan dan tidak dihitung.
3. Centang item yang sudah selesai.
4. Klik **Simpan Sekarang**, atau biarkan **auto-save** (tiap 10 menit saat aktif).
5. Progres tersimpan per periode; aman jika halaman tertutup.

## 4. Riwayat & Perbandingan
1. Buka **Riwayat** untuk melihat snapshot tiap periode.
2. Gunakan **Bandingkan Periode** untuk melihat selisih antar periode.

## 5. Ekspor
1. Buka **Ekspor**.
2. Pilih periode & metode laporan.
3. Klik **Export Excel** / **Export PDF**.
4. PDF memuat identitas operator, Kepala Sekolah + NIP/NIY, dan ruang tanda tangan.

## 6. Profil
1. Klik **Ubah Profil ▼**.
2. **Ubah Data OPS**: nama, sekolah, NPSN, email, No HP, status kepegawaian + NIP/NIY operator.
3. **Ubah Data KEPSEK**: nama, status, NIP/NIY kepala sekolah.
4. **Ubah Password** bila perlu.

## 7. Masalah Umum
| Gejala | Solusi |
|---|---|
| Lupa password | Hubungi admin untuk reset. |
| Progres tidak muncul | Klik Muat Ulang / pastikan sudah Simpan. |
| Persentase tidak 100% | Pastikan metode update sudah dipilih; item metode lain tidak dihitung. |
| No HP kehilangan 0 | Pastikan kolom NoHP berformat Plain Text; isi ulang di Profil. |
