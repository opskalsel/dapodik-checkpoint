# Panduan Admin — Dapodik Checkpoint

## 1. Masuk
Gunakan **Masuk Admin**. Ganti password default segera.

## 2. Dashboard Admin
- Melihat total pengguna, operator, sekolah unik, snapshot, sudah/belum mulai.
- Tabel pengguna menampilkan semester, tahun, progres terakhir, dan login terakhir.

## 3. Tambah User
1. Buka **➕ Tambah User Baru**.
2. Isi data lengkap, pilih **Role** (operator/admin).
3. User wajib mengganti password saat login pertama.

## 4. Kelola Pengguna
- **🔑 Reset Password**: membuat password sementara (sampaikan aman).
- **🗑️ Reset Checklist**: hapus progres + history user (tidak bisa dibatalkan).
- **💣 Reset Database**: hapus progres + history + data kepala sekolah (tidak bisa dibatalkan).

## 5. Ekspor Rekap
- **Export Excel/PDF Rekap**: daftar operator, sekolah, semester, tahun, progres terakhir.

## 6. Pemeliharaan Rutin
- Mingguan: cek laporan pemakaian (email otomatis).
- Harian: backup otomatis berjalan (cek folder backup).
- Awal tahun ajaran: jalankan SOP tahun ajaran baru (lihat OPERASIONAL).

## 7. Keamanan
- Jangan bagikan password admin.
- Gunakan reset password, bukan membagikan password.
- Audit tindakan admin tercatat di SyncLog.
